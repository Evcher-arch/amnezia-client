# AmneziaVPN Share — 100% рабочая версия

**Статус: работоспособность подтверждена пользователем 9 октября 2026 года.**

Подтверждение после установки последнего исправления: «Все восстановилось!».
Отметка относится к проверенной установке Windows с XRay и встроенной
раздачей Tunnel Sharing. Это контрольная точка для возврата к рабочей версии.

- Репозиторий: `Evcher-arch/amnezia-client`.
- Ветка: `codex/tunnel-sharing`.

## Состав исправления

- Корректное завершение старого `tun2socks` по полному пути с ожиданием
  освобождения адаптера; другая установка с тем же именем EXE не затрагивается.
- Освобождение TUN при закрытии управляющего соединения клиента.
- Повторное назначение уже существующего IP без ложного таймаута Error 101.
- UTF-8 BOM для запуска скрипта раздачи в Windows PowerShell 5.1.
- Ожидание готовности IPv4 TAP перед настройкой маршрутов.
- Синхронизация маршрутов XRay с TAP во время работы, включая поздние
  DNS-маршруты `/32`, и удаление принадлежащих раздаче маршрутов при остановке.
- Сохранение исходной ошибки запуска после завершения очистки.
- SOCKS-пароль больше не выводится вместе с аргументами запуска процесса.

## Проверки перед сохранением

- Сборка службы MSVC Release завершилась успешно.
- SHA-256 установленной службы совпал с результатом сборки.
- Установленный `Share.ps1` побайтово совпал с локальным исходным файлом.
- Интеграционный тест выполнил три цикла создания TUN, повторного назначения
  IP и освобождения адаптера после закрытия управляющего соединения.
- Проверка замены работающего `tun2socks` оставила ровно один TUN.
- Тест маршрутов проверил первоначальные, поздние и удалённые маршруты,
  отсутствие дубликатов, учёт очистки и защиту чужого маршрута.
- Скрипт разобран парсером Windows PowerShell 5.1 без ошибок.
- HTTP и HTTPS через TAP-мост прошли; восстановление работы раздачи
  на подключённом устройстве затем подтвердил пользователь.

Интеграционный тест: `tools/tun-lifecycle-test` (запускать при закрытом
клиенте и отключённом VPN). Тест маршрутов без изменения сети:

```powershell

```
